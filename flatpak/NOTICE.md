# NOTICE — Flathub Generative AI policy

Per [Flathub Requirements — Generative AI policy](https://docs.flathub.org/docs/for-app-authors/requirements):

1. **Flathub manifests must not contain AI-generated or AI-assisted content.** Disclosure does not exempt manifests from this restriction.
2. **AI tools or agents must not open or automate Flathub submission pull requests**, or generate their commit messages, descriptions, review comments, or replies.

The YAML/desktop/metainfo files under this directory were prepared as **research scaffolding / local self-host drafts** by an assistant. They are **not** submission-ready for flathub/flathub.

Before any Flathub PR:

- A human (ziyuw-Plank) must **author the Flathub manifest and metadata from scratch** (or thoroughly rewrite so the Flathub copy is human-written).
- Do **not** ask an agent to open the flathub/flathub PR, write the PR body, or reply to reviewers.
- Follow `HUMAN-SUBMISSION-STEPS.md` only after deciding Flathub is still worth attempting despite `FLATHUB-ASSESSMENT.md`.

This packaging repo may keep these drafts for local Flatpak experiments and documentation.
